دخول SharePoint 📁
المعالجة التقنية: ESP32 + HC-SR04
فكرة التنفيذ:

توجيه حساس المسافة لكشف الأجسام؛ عند اقتراب اليد، يرسل ESP32 إشارة للمحرك لفتح الغطاء.

التوصيل: Trig (GPIO 5) | Echo (GPIO 18) | Servo (GPIO 13)
void loop() {
  long duration = pulseIn(echoPin, HIGH);
  if (duration < 1000) servo.write(90);
}
منهجية الترشيح الفيزيائي
خطة التنفيذ:

ترتيب طبقات (حصى، رمل، فحم، قطن) داخل حاوية شفافة لملاحظة مراحل التنقية خطوة بخطوة.

المعالجة التقنية: ESP32 + MQ-2
فكرة التنفيذ:

قراءة القيم التماثلية من مستشعر الدخان؛ عند تجاوز الحد، يطلق الـ ESP32 جرس الإنذار.

التوصيل: MQ-2 (GPIO 34) | Buzzer (GPIO 2)
