سلة المهملات الذكية

المشاركات: جنى الوذناني، تبيان الحاج، رباب خبراني، وسن فقيهي

Arduino HC-SR04 Servo

الفكرة

فتح الغطاء تلقائيًا عند اقتراب اليد باستخدام حساس مسافة لتقليل التلامس.

نواتج تعلم

  • عمل الحساسات والمحركات.
  • برمجة Servo وفقًا للمسافة.
  • تصميم ميكانيكي للغطاء.

المكونات

  • Arduino Uno
  • HC-SR04
  • Servo SG90
  • أسلاك + مفصلات + مزود طاقة
خطوات التنفيذ
  1. تثبيت السيرفو على الغطاء بوصلة مرنة.
  2. توصيل HC-SR04 (VCC/GND/TRIG/ECHO).
  3. شرط: المسافة < 20 سم → فتح، ثم إغلاق.
نموذج كود Arduino 
// سلة المهملات الذكية
#include <Servo.h>
Servo lid;
const int trig=9, echo=10, servoPin=6;
const int openAngle=90, closeAngle=0, threshold=20;

long readCM(){
  digitalWrite(trig,LOW); delayMicroseconds(2);
  digitalWrite(trig,HIGH); delayMicroseconds(10);
  digitalWrite(trig,LOW);
  long d=pulseIn(echo,HIGH,30000);
  return d*0.034/2;
}
void setup(){
  pinMode(trig,OUTPUT); pinMode(echo,INPUT);
  lid.attach(servoPin); lid.write(closeAngle);
}
void loop(){
  long distance = readCM();
  if(distance>0 && distance<=threshold){
    lid.write(openAngle); delay(1200);
  } else {
    lid.write(closeAngle);
  }
  delay(80);
}

Science Sustainability

الفكرة

طبقات: قطن → فحم نشط → رمل → حصى (من الأكبر مسامًا إلى الأصغر).

مواد

  • زجاجة/أنبوب شفاف
  • قطن، فحم، رمل، حصى
  • أكواب قبل/بعد

سلامة

  • ماء عكر آمن فقط (تراب نظيف).
  • غسل اليدين بعد التجربة.

خطوات

  1. ثقوب تصريف صغيرة أسفل الوعاء.
  2. ترتيب الطبقات من الأكبر للمسام الأصغر.
  3. سكب الماء العكر والملاحظة/التسجيل.
  4. تعديل السمك لتحسين النتائج.

Safety Sensors Arduino

الفكرة

استشعار دخان/لهب وإطلاق إنذار ضوئي/صوتي.

المكونات

  • MQ-2 أو حساس لهب
  • Buzzer + LED
  • Arduino

سلامة

  • ممنوع اللهب الحقيقي داخل الصف.
  • استخدمي محاكاة/مواد تعليمية آمنة خارج المختبر إن لزم.
نموذج كود (MQ-2) 
const int mqA0=A0, buz=7, led=8; 
int threshold=350;
void setup(){ pinMode(buz,OUTPUT); pinMode(led,OUTPUT); }
void loop(){
  int val=analogRead(mqA0);
  if(val >= threshold){ digitalWrite(led,1); tone(buz,2000); }
  else{ digitalWrite(led,0); noTone(buz); }
  delay(100);
}
