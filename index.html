دليل تنفيذ سلة المهملات الذكية
المعالجة (Brain): ESP32 NodeMCU
توصيل حساس HC-SR04: الـ Trig بمنفذ GPIO 5، والـ Echo بمنفذ GPIO 18.
توصيل محرك Servo: سلك الإشارة بمنفذ GPIO 13.
الطاقة: يتم التزويد عبر كابل USB أو بطارية 5V.
المنطق البرمجي (Logic):
if (distance < 20) {
  servo.write(90); // فتح الغطاء
  delay(3000); // بقاء مفتوح
} else {
  servo.write(0); // إغلاق
}
منهجية التصميم الهندسي (EDP)
**التساؤل**: كيف نفتح السلة دون تلامس؟
**الإنشاء**: تركيب الحساسات وبرمجة الـ ESP32 للتحكم في الغطاء.

المواد الهيكلية:
حاوية شفافة مقسمة لطبقات.

دليل تنفيذ كاشف الحريق الذكي
المعالجة: ESP32 NodeMCU
حساس الدخان (MQ-2): توصيل المخرج التماثلي بمنفذ GPIO 34 (ADC).
التنبيه: توصيل Buzzer ومنفذ LED بمنفذ GPIO 2.
المنطق البرمجي:
int val = analogRead(34);
if (val > threshold) {
  digitalWrite(2, HIGH); // إنذار
  Serial.println("خطر حريق!");
}
